# 07 — Personal Social Agent

**状态：未开工**  
**优先级：占位**

## 目标

不是让 AI 替你做人，而是帮你记住长期关系上下文：最近工作、上次聊天、偏好、曾推荐内容、下次可聊话题。

## 隐私注意

此人际数据敏感；开工前必须明确存储位置、是否加密、是否进 git。

## 开工前必问

1. 这次要做到什么深度？（骨架 / MVP / 可发布）
2. 是否对接已有通讯录/笔记资产？
3. 是否允许写真实代码 / 接 MCP / 生图 / 发内容？数据是否允许提交到 GitHub？

## 禁止偷懒

- 禁止把真实好友隐私明文推公共仓库
- 禁止做成“代发消息机器人”而无边界
- 禁止无同意机制的自动化触达
