# 02 — Personal AI OS（产品化入口）

**状态：未开工（产品化未开始；本仓库根目录已是 OS 骨架）**  
**优先级：第 2（长期资产）**

## 目标

把仓库根上的 `knowledge/`、`memories/`、`prompts/`、`.cursor/`、`automation/` 产品化为一套可日常运行的个人 AI 操作系统——不是 ChatGPT 套壳。

## 本目录用途

放 OS 产品化笔记、路线图、入口说明与验收清单；实现仍落在仓库根约定目录。

## 已有根资产

- `prompts/` — 完整提示词库
- `.cursor/` — Rules / Agents / Skills
- `knowledge/` — 主题知识库
- `memories/` — 偏好 / 教训 / 决策
- `automation/` — 自动化占位
