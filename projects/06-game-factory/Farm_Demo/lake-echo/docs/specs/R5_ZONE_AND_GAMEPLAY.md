# R5 Zone + Gameplay Spec

## Camera / input

- zoom `(2,2)` nearest · WASD · Space tool · E interact · Tab inventory · 1–4 tools
- Chinese HUD

## Per-zone gameplay

| Zone | Collision | Interact |
|------|-----------|----------|
| Z1_FARM | water/cliff block; farmland hoe/plant/water/harvest | farmhouse door → interior; chest; animals feed |
| Z2_RIVER | water block; bridges walkable | fish spots on bank; bridge no fall |
| Z3_TOWN | buildings block | NPC dialogue; stalls toast only (no economy) |
| Z4_STATION | rails decorative + edge block | platform toast「列车停靠中」; no boarding |
| Z5_TERRACE | cliff block; stairs walkable | view crops; optional hoe plots |
| Z6_LAKE | deep water block | pier toast; lighthouse exterior only Wave6 |

## Out of scope (R5)

Day/night, save, economy, train ride, lighthouse interior, story quests.
