# VISUAL BIBLE — Oakhaven（风格锁）

**锚点图：** `docs/ref/oakhaven_overview.jpg`  
**引擎约定：** Tile 16×16 · 地图 192×128 · Camera zoom 2 · Nearest filter · 中文 UI  

## 画风

- 类型：16-bit 顶视偏斜像素（类星露谷 cozy）  
- 饱和：暖绿草地、亮蓝水体、红谷仓、深褐屋顶  
- 禁止：写实 3D、赛博紫、扁平矢量 UI、过大描边卡通  

## 尺寸契约

| 类别 | 画布 / 单元 | 备注 |
|------|-------------|------|
| 地形瓦片 | 16×16 | `tileset_master.png` |
| 玩家 | 48×48 格，4 行×≥4 列走循环 | 行序：下、左、右、上 |
| NPC | 侧视横条，帧宽≈高 | flip_h 向左 |
| 动物 | 横条，帧高=图高 | chicken/sheep/cow |
| 建筑道具 | 脚底对齐，透明底 | PIL gen + qa checker |

## 调色板（主色，可扩展但勿漂移）

- 草：`#5FA86A` `#3E7A48`  
- 土：`#8B6B4A` `#C4A574`  
- 水：`#4A9FD8` `#2E6FA8`  
- 屋瓦：`#6B4A3A` `#8B5A4A` / 蓝顶 `#4A6FA8`  
- 谷仓红：`#B03A32`  

## 素材管线

1. 优先改 `tools/gen_*.py`（确定性像素）  
2. 外网下载仅限 **明确 CC0/可商用**；写入 `docs/ASSET_ATTRIBUTION.md`  
3. AI 生图必须：抠图 → 缩放到契约尺寸 → 调色板约束 → `assets/qa/checker_*.png`  
4. 角色新增必须同时有：设计卡（名/职业/一句话）+ 精灵表  

## 动效最低标准（类星露谷「活」）

- 角色：走循环可辨（≥4 帧）  
- 作物：≥3 生长阶段可见切换  
- 水：涟漪或动画瓦片  
- 环境：≥3 类持续 FX（烟/雾/树摇/车动/灯闪）  

## 禁止

- 单帧角色冒充 walk  
- 与锚点图区域相对位置严重错位却声称「一比一」  
- 无 attribution 的版权素材入库
