# Asset Spec — Oakhaven（世界服务素材）

> 素材服务世界，不是世界迁就素材。

## 入库前

1. 符合 `VISUAL_BIBLE.md` 尺寸契约与调色板  
2. 透明底 +（如需）棋盘格 QA  
3. Attribution：`ASSET_ATTRIBUTION.md`  
4. 建筑/道具默认脚底对齐、可接地  

## Agent 提问

新增素材前必须回答 `GAME_VISION.md` 的五问；无法回答则先回 `WORLD_DESIGN` 改构图，而不是开画。

## 与 Asset Agent

仓库角色 `Asset`（`prompts/04-domain/asset.md`）执行生图/抠图/导入；本文件是 Oakhaven 专用规范覆盖层。
