# Art Direction — Oakhaven

锚点：`VISUAL_BIBLE.md` · `PIXEL_PROMPT.md` · Skill `game-world-art-director`

## 一句话

**场景构图优先，瓦片拼接次之。** 材质统一、层次、道路、水体、聚落密度、消重复。

## 必须一致

| 项 | 规则 |
|----|------|
| 透视 | 单一 3/4 顶视；建筑/树/路/栅栏同一透视系 |
| 像素 | Nearest · 无模糊缩放 · 统一像素密度 |
| 光照 | 全局同一高光/阴影方向 |
| 调色板 | 服从 `VISUAL_BIBLE.md`；禁止漂移赛博紫/写实 |
| 层次 | Macro / Mid / Micro 三级都要有，禁止只堆 Micro |

## 密度梯度（禁止均匀铺满）

- 林缘密、林内更密、农田路径带状、城镇斑块、安静区留白  
- 物体成簇：林/花/石/栅栏/邻里，禁止独立撒点

## 建筑落地

每栋建筑必须有：院子、入口、小路、栅栏/植被、邻接关系、脚底接地。  
禁止孤岛精灵。

## 优先级（返工顺序）

1. Global composition  
2. Region shape  
3. Terrain transitions  
4. Road structure  
5. Building relationships  
6. Vegetation clustering  
7. Mid decoration  
8. Micro details  

## 最终观感目标

玩家第一印象应是：**「这是一个地方」**，而不是「这是一张 TileMap」。
