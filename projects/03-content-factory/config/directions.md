# 方向配置

## 硬规则（必须遵守）

1. **一次只做一个小方向**：山水画讲解 与 传统纹饰 分开做，禁止同篇/同图混搭。
2. **AI 资讯封面必须信息上图**：关键数字、对比口径、生效时间要用排版进图（优先 `scripts/render_ai_news_cover.py` 一类字体排版），禁止只有抽象装饰、没有新闻信息。
3. **发布**：默认 `local_only`，不自动发小红书。

## culture_painting（讲画）
- 水墨山水名作/空间/笔墨结构
- 生图：纯山水氛围；禁止纹样边框、器物装饰混入

## culture_pattern（讲纹饰）
- 器物 / 服饰 / 建筑彩画上的纹样讲解
- 生图：纹样提取与创新组合壁纸；禁止硬贴一张完整「假名画」当主体

## ai_news
- 厂商额度、促销、重置、计费口径
- 封面：标题 + 关键数字 + 分行对照 + 免责声明

## 输出形态
小红书图文 + 封面/壁纸（按小方向）+ 口播提纲
