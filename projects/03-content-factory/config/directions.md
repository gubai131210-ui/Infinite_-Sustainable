# 方向配置

## 硬规则（必须遵守）

1. **传统文化分两条轨，一次只开一条**
   - `culture_painting`：只讲水墨山水 / 只生成山水氛围图
   - `culture_pattern`：只讲纹饰；生图只能是 **纹饰×纹饰组合**（如回纹边 + 卷云铺）
   - **禁止**：纹饰边框套水墨画心、山水场景里贴花纹
2. **AI 资讯封面必须信息致密排版**：双栏对比 + 换算条 + 时间线 + 行动清单；禁止大面积留白抽象图。配色可深色蓝系。优先 `scripts/render_ai_news_cover.py`
3. **发布**：默认 `local_only`

## culture_painting（讲画）
- 空间/笔墨/近中远
- 生图：纯山水；禁止任何器物纹样边框

## culture_pattern（讲纹饰）
- 母题讲解 + 母题组合壁纸
- 生图：程序纹样或纯装饰纹样；禁止山/树/亭/雾气画意
- 渲染脚本示例：`scripts/render_pattern_yunwen_huiwen.py`

## ai_news
- 额度/活动/口径
- 封面必须让人「看图就能懂新闻」
