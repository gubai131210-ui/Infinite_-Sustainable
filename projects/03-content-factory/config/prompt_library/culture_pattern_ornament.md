# 传统文化 · 纯纹饰组合（只讲纹饰）

纹饰×纹饰。禁止山水。

## 必写

1. `pure ornamental pattern / textile-lacquer motif`（不是风景）
2. 点名母题：`huiwen (key-fret / meander)` + `yunwen (rolling cloud scroll)`
3. `flat vector OR fine line ornament`, `seamless / tiled / border+field`
4. 材质感：`lacquer panel` / `brocade` / `ceramic shoulder pattern`（选一）
5. 负向：**整段禁止** mountain, shan-shui, pavilion, tree, misty peaks, ink landscape

## 主模板（壁纸）

```text
SUBJECT: pure traditional Chinese ornamental pattern composition combining (1) huiwen key-fret geometric border frames and (2) densely tiled yunwen rolling cloud-scroll motifs filling the inner field — pattern x pattern only
STYLE: flat decorative craft design like lacquerware shoulder pattern or brocade repeat, clean vector-like curves, precise line weight, symmetrical rhythm, archival museum pattern plate aesthetic
LIGHTING: even flat lighting, no dramatic shadows, no photoreal 3D
COMPOSITION: vertical 3:4 full-bleed wallpaper; outer double meander border; inner field packed with cloud scrolls; dense, elegant, not sparse
MOOD: ceremonial, craft-precise, indigo navy + cream + cinnabar + muted gold palette
TECHNICAL: ultra sharp edges, high detail repeats, seamless craft print look

NEGATIVE: mountain landscape, shan-shui, ink wash scenery, trees, rocks, pavilion, fisherman, misty peaks, figurative painting, photoreal texture overload, watermark, text, logo, western baroque ornament
```

## 器物应用模板（推荐）

纹饰必须落到生活可用物上（服飾、家具、漆盒、杯墊等），并在文案写清作用/象征/常用。

```text
SUBJECT: a practical daily-life object — [silk robe / lacquer jewelry box / wooden furniture panel / ceramic tea caddy], surface decorated with traditional Chinese [yunwen cloud-scroll / huiwen key-fret] pattern clearly readable
STYLE: product photography + craft documentation, sharp material texture
LIGHTING: soft studio light
COMPOSITION: vertical 3:4, object fills frame, plain backdrop, pattern is the hero
MOOD: wearable / usable culture, not museum flat pattern plate only
NEGATIVE: mountain landscape, shan-shui, pavilion, misty peaks, ink wash scenery, watermark, logo, unreadable fake glyphs
```
