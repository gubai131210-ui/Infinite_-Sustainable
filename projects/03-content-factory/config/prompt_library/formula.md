# 通用 6 槽公式（SurePrompts 2026）

写提示词时按顺序填满，缺槽就容易糊、空、串风格。

```text
1. SUBJECT     主体是什么（越具体越好）
2. STYLE       媒介/流派（ink wash / flat vector / editorial poster…）
3. LIGHTING    光线（soft diffused / paper ambient / studio flat…）
4. COMPOSITION 构图（vertical 3:4, rule of thirds, negative space %…）
5. MOOD        情绪与材质（calm, archival, high-contrast…）
6. TECHNICAL   比例、清晰度、seed、负向词
```

## 检查清单

- [ ] 主体是否可被画出（不是抽象口号）
- [ ] 是否写明 **比例**（小红书封面默认 3:4）
- [ ] 是否写明 **要什么 + 不要什么**（Negative）
- [ ] 文化题材是否写清 **painting-only 或 pattern-only**
- [ ] 资讯题材是否写清 **字号层级 / 模块数量**；中文优先程序排版

## 负向词底稿（可追加）

```text
blurry, low quality, watermark, logo, extra fingers, deformed,
random english gibberish, duplicated text, crowded collage,
photoreal skin pores (unless needed)
```

水墨追加：`color, saturation, chinoiserie, ornamental cloud border, dragon motif filling sky`

纹饰追加：`mountain landscape, shan-shui, trees, pavilion, misty peaks, ink wash scenery, figurative painting`
