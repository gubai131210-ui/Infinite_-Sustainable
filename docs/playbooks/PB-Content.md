# PB-Content

**用途：** 自媒体/内容工厂图文产出。  
**证据强度：** 中（产物路径 + Critic；生图则含资产检查）

## 链

```text
Conductor → Researcher → Content → (Asset 若需图) → Critic → Memory?
```

## 验收（默认）

- [ ] 产出落在约定 `outputs/` 或 pipeline 路径
- [ ] 标题/正文/视觉说明齐全（按当次 brief）
- [ ] 无未标注的猜测事实

## 禁止偷懒

- 禁止跳过事实核查直接发文案
- 禁止生图无 prompt 记录
- 禁止把草稿当已发布
