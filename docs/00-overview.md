# 00 — 概览：价值层级与四大系统

## 价值层级（冲 L4–L5）

| 层级 | 做法 | 15 天后留下什么 |
|------|------|----------------|
| L1 | 让 AI 写代码 | 几个项目 |
| L2 | 学会用 Agent 开发 | 开发效率提升 |
| L3 | Rules / Skills / Subagents | 一套自己的 Agent 能力 |
| L4 | MCP + Automations + 数据 | 自动化系统 |
| L5 | 多 Agent + 评价 + 记忆 + 持续运行 | 个人 AI Operating System |

## 四大系统

```text
                    你的个人 AI OS
                          │
          ┌───────────────┼───────────────┐
          │               │               │
      Knowledge        Agent Lab       Automation
          │               │               │
      工作/生活知识       学习Agent         日常任务
      项目经验           Reviewer          内容生产
      兴趣/资料           Researcher        信息整理
      技术笔记           Coder             周报
          │               │               │
          └───────────────┼───────────────┘
                          │
                      Content
                          │
                  小红书 / 视频 / Blog
```

## 15 天重点四件套（优先级）

1. Agent Lab — 能力本身
2. Personal AI OS — 长期资产
3. AI Content Factory — 影响力
4. 一个真正发布的产品 — Portfolio

Industrial Copilot / Game Factory / Social Agent 已占位，按需插入。

## 无限 Token 正确用法

用 Token 换经验，不是换代码量：

1. 多模型对比
2. 多 Agent 对比
3. 长时间运行
4. 失败后自动修复
5. 建立评估体系
6. 建立自动化循环

## 可迁移原则

重点沉淀：**Agent 方法、代码、Rules、Skills、MCP、知识库、自动化架构**，不把经验绑死在某一个模型上。
